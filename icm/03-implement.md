# 03 – Implement

## Purpose
Write or modify the actual code according to the approved design and coding standards.

## Inputs (load only these)
- This file
- The latest approved `[feature]-design.md`
- coding-standards.md
- tech-stack.md
- architecture-principles.md (only sections relevant to the change)

Do **not** load requirements or review files unless the human explicitly asks.

## Process
1. Confirm you are implementing against the approved design (quote the relevant parts).
2. Plan the minimal set of files / modules to change or create.
3. Implement following coding-standards.md and the design contracts.
4. Keep changes focused — one logical concern at a time when possible.
5. Note any deviations from the design and why.
6. Produce clear implementation notes for the next stage.

## Outputs
- Code changes (described or written)
- `icm/artifacts/[feature]-impl-notes.md` (what was done, key decisions, remaining work)

## Done When
Code is ready for review and testing. No final docs or PR description yet.
